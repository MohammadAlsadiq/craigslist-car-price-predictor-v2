# Write individual report parts without merge conflicts

Each student writes in `reports/sections/MX/section.md`. M4 builds `reports/final/project_report.pdf` from those approved sections. Do **not** simultaneously edit one shared DOCX.

M1: dataset, source/license, ethics, all eight processing steps, counts, EDA and captions. M2: features, split, baseline, model pipeline, MAE/RMSE/R² values from saved metrics, limitations. M3: target user requirements, Streamlit UI usage, screenshots and invalid-input examples. M4: title/member roster, objectives, short comparison with existing services, architecture, testing/reproducibility, conclusion, references, individual contributions, final formatting.

Final report must include title/members; introduction; user/client requirements; objectives; market/existing solution review; dataset/source; architecture; processing; AI evaluation; screenshots/results; limitations; conclusion; references; individual contributions.
