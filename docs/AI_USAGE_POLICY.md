# AI usage report (mandatory even if not used)

Each student maintains `ai_usage/MX/log.md`: date, tool, prompt, suggestion, what you checked/tested, any corrections and which parts you independently wrote. M4 compiles it into `reports/final/AI_Usage_Report.md` (or PDF). If no AI tool was used, explicitly state that. Do not paste unverified chatbot claims as measured results.
