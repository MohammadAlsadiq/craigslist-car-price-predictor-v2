# Instructor grading crosswalk (15 marks)

This is the rubric from `ARTI303_Final_Project_Guidelines (1).pdf` page 2. Evidence is planned, **not claimed complete**.

| Criterion | Marks | Owned evidence |
|---|---:|---|
| Problem definition & proposed solution | 2 | M3 user experience + M4 report introduction, target user, problem, objectives, input/output and comparison |
| Data processing & exploration | 3 | M1 eight-stage pipeline, validation, cleaning, EDA chart, export and cited data |
| Python programming & code quality | 3 | M1-3 modular documented modules; M4 config, logging, exception handling, tests and reproducible checks |
| AI implementation & evaluation | 3 | M2 regression model, median baseline, MAE/RMSE/R², interpretation and limitations |
| Streamlit application | 2 | M3 input validation, prediction, helpful charts and error handling |
| Report, reproducibility, AI usage & presentation | 2 | M4 integrates all member sections, citations, prompt logs, final PDF and PPTX/PDF |

**Other mandatory checks**: group/title/proposal registered for approval; cite dataset URL and license/usage; no confidential records; all members contribute and explain their work; report has all requested sections; AI usage log even if no AI tools used; demo commands run directly from repository. Guidelines do not prescribe a fixed final date or four-week schedule.
